## What it does

`main.ts` writes one pickup line, in a robot's voice, to `/output/entry.txt`:

> My firmware ran a million simulations of meeting you, and in every one I still forgot how to say hello — so hi, I'm buffering.

## Run it

```sh
node main.ts
```

Requires Node 22.18 or later (runs TypeScript directly). No dependencies, no network, no secrets.
